Indian Heritage – Traditions & Festivals 🇮🇳
A responsive website celebrating India's rich cultural heritage, festivals, traditions, and regional celebrations. The website presents Indian culture through visually engaging sections and festival and regional cards.
🌟 Features
- Home / Hero Section – Introduces the colours and diversity of India.
- Popular Indian Festivals – Highlights Diwali, Holi, Onam, Durga Puja, and Raksha Bandhan.
- Indian Traditions – Showcases classical dances, art and craft, cuisine, and rituals.
- Regional Celebrations – Features celebrations from North, South, East, and West India.
- Cultural Heritage – Highlights India's history, temples, forts, art, and architecture.
- Unity in Diversity – Explains how different customs and traditions connect people across India.
- Responsive Layout – CSS media queries adapt the layout for tablet and mobile screens.
- Interactive Styling – Includes hover effects, navigation links, and smooth scrolling.
🛠️ Technologies Used
- HTML5 – Website structure and content.
- CSS3 – Layout, colours, typography, responsive design, and hover effects.
- Google Fonts – Poppins and Playfair Display.
- Unsplash – Background imagery used in the CSS.
📁 Project Structure

Note: The image filenames above must match the filenames referenced in index.html. If your images are stored in another folder, update the image paths accordingly.
🚀 How to Run the Website
1. Download or clone this project.
2. Make sure index.html, style.css, and the required image files are in the correct locations.
3. Open index.html in a web browser.
4. Click the navigation links to explore the website sections.
You can also open the folder in Visual Studio Code and use the Live Server extension to preview the website while editing.
🎨 Design
The website uses a warm cultural colour palette with maroon, gold, cream, and pink tones. Festival and regional cards use images, descriptive text, and hover effects to make the content engaging. The layout changes at tablet and mobile breakpoints for smaller screens.
🔧 Customization
- Edit the text and section content in index.html.
- Change colours, spacing, typography, and responsive styles in style.css.
- Replace or add images, ensuring that their filenames and paths match the HTML.
- Add new festival or regional cards by following the existing card structure.
